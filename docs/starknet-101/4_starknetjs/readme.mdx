# WTF Starknet 4: Starknet.js

[Starknet.js](https://www.starknetjs.com/) is a JavaScript library to interact with [Starknet](https://starknet.io/), typically in script or a decentralized applications. Starknet.js is inspired by [Ethers.js](https://github.com/ethers-io/ethers.js), so it's easier if you have experience with it. 

> If you are not familiar with Ethers.js, check [WTF Ethers Tutorial](https://github.com/WTFAcademy/WTF-Ethers).

## 1. Set up the example

This lesson uses Starknet.js 10.8.0 and Node.js 22+. From this lesson directory run `npm ci`, then set `STARKNET_RPC_URL` and `CONTRACT_ADDRESS` to the RPC endpoint and deployment address for the Cairo contract below.

Run `node wtf_starknet.js` to read the contract. On a local devnet, set `ADDRESS` and `PRIVATE_KEY` for a disposable test account and add `--write` to try a state change and read its event. Use an endpoint that supports the SDK's RPC version.

## 2. Contract

Deploy this contract to a local devnet to try the example. It stores `balance`, exposes a setter and getter, and emits `log_data` on writes.

```rust
#[starknet::contract]
mod HelloCairo {
    // storage variable: balance
    #[storage]
    struct Storage {
        balance: felt252,
    }

    // event
    #[event]
    #[derive(Drop, starknet::Event)]
    enum Event {
        LogData: LogData,
    }

    #[derive(Drop, starknet::Event)]
    struct LogData {
        #[key]
        value: felt252,
    }

    // set balance
    #[external(v0)]
    fn set_balance(ref self: ContractState, amount: felt252) {
        self.balance.write(amount);
        self.emit(LogData { value: amount });
    }

    // read balance
    #[external(v0)]
    fn read_balance(self: @ContractState) -> felt252 {
        self.balance.read()
    }
}
```

## 3. Read, write, and inspect a receipt

The complete script, `wtf_starknet.js`, initializes `RpcProvider` and passes it to `new Contract({ abi, address, providerOrAccount: provider })`. The optional write path connects `new Account({ provider, address, signer })`, calls the setter, and checks the receipt before reading events.

See the [Starknet.js docs](https://starknetjs.com/docs/) for supported RPC versions and optional contract call settings.
