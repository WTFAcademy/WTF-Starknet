# WTF Starknet 5: Starknet dApp

This lesson connects a wallet and sends a mint call to the [tutorial ERC-721](https://github.com/WTFAcademy/WTF-Academy-StarkNet-Hackathon/tree/main/src/contracts/ERC721).
Use an address for that contract on the same network as the connected wallet.

## Install Starknet React

Starknet React 5.0.3 declares Starknet.js 8 and React 18 peer dependencies.
The standalone JavaScript lesson uses Starknet.js 10.

```sh
npm install @starknet-react/core@5.0.3 @starknet-react/chains@5.0.3 starknet@8.9.2 react@18.3.1 react-dom@18.3.1
```

Wrap your application in a provider for Sepolia. `useInjectedConnectors`
discovers installed wallets and can show recommended wallets when none are found.

```jsx
import { sepolia } from "@starknet-react/chains";
import {
  argent, braavos, publicProvider, StarknetConfig, useInjectedConnectors,
} from "@starknet-react/core";

const provider = publicProvider();

export function StarknetProvider({ children }) {
  const { connectors } = useInjectedConnectors({
    recommended: [argent(), braavos()],
    includeRecommended: "onlyIfNoConnectors",
  });

  return (
    <StarknetConfig chains={[sepolia]} provider={provider} connectors={connectors}>
      {children}
    </StarknetConfig>
  );
}
```

## Connect and disconnect a wallet

`useConnect` lists connectors. `useAccount` reports the active address, and
`useDisconnect` ends the connection in the app.

```jsx
import { useAccount, useConnect, useDisconnect } from "@starknet-react/core";

export function Wallet() {
  const { address } = useAccount();
  const { connect, connectors } = useConnect();
  const { disconnect } = useDisconnect();

  if (address) return <button onClick={() => disconnect()}>{address}</button>;
  return connectors.map((connector) => (
    <button key={connector.id} onClick={() => connect({ connector })}>
      {connector.name}
    </button>
  ));
}
```

## Send the mint call

`useSendTransaction` sends the calls after the connected wallet approves them.
The tutorial contract's `mint` takes no arguments. Use the resulting transaction
hash with `useTransactionReceipt` to check the receipt.

```jsx
import {
  useAccount, useSendTransaction, useTransactionReceipt,
} from "@starknet-react/core";

export function Mint({ contractAddress }) {
  const { address } = useAccount();
  const calls = contractAddress
    ? [{ contractAddress, entrypoint: "mint", calldata: [] }]
    : [];
  const { send, data, isPending, error } = useSendTransaction({ calls });
  const hash = data?.transaction_hash;
  const { data: receipt } = useTransactionReceipt({ hash, enabled: Boolean(hash), watch: true });

  return (
    <>
      <button disabled={!address || !calls.length || isPending} onClick={() => send()}>
        Mint
      </button>
      {hash && <p>{hash}</p>}
      {receipt?.isSuccess() && <p>Confirmed</p>}
      {error && <p>{error.message}</p>}
    </>
  );
}
```

See [Starknet React](https://github.com/apibara/starknet-react) for hook
documentation and [Starknet Wallet Standard](https://github.com/starknet-io/starknet-js) for wallet integration through Starknet.js.
